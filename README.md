An AI-powered Gmail automation system built using Python, FastMCP, Gmail API, and Claude Desktop.

This project uses the Model Context Protocol (MCP) to allow Claude Desktop to securely interact with Gmail in real time. The system can read emails, classify inbox categories, detect potential phishing or spam emails, summarize inbox activity, and automatically label unread emails.

Features:
• Gmail API integration with OAuth2 authentication
• Intelligent email classification
• Spam and phishing detection
• Auto-labeling of unread emails
• Inbox summarization and categorization
• Claude Desktop MCP integration

Tech Stack:
Python • FastMCP • Gmail API • OAuth2 • Claude Desktop • Google Cloud Platform
